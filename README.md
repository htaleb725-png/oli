# منظومة مكتب النائب م. علا عودة الناشي (مجلس النواب العراقي)

منظومة إلكترونية متكاملة لإدارة شؤون المراجعين، الطلبات والكتب الرسمية، المقابلات، والتنظيم الجماهيري مع الربط الحصري والمباشر بـ **Google Sheets** كقاعدة بيانات مركزية و **Google Drive** كأرشيف سحابي للصور والوثائق.

---

## 📊 قاعدة بيانات Google Sheets وأرشيف Google Drive الحصري

تم تصميم وهندسة النظام ليعتمد كلياً على بيئة **Google Workspace** دون الحاجة لأي قواعد بيانات أخرى:

1. **Google Sheets كقاعدة بيانات مركزية**:
   - كافة أقسام المنظومة (سجل المراجعين، الطلبات، مقابلات النائب، الكتب الرسمية، صكوك المساعدات، السجل التنظيمي، سجل العمليات) ترتبط وتخزن في جداول Google Sheets تلقائياً وبلحظتها.
   - يتم تنظيم الجداول وتنسيقها رسمياً مع تثبيت الصفوف الرئيسية والعناوين.
   - يتم المزامنة والحفظ في الخلفية دون أي تعطيل لواجهة المستخدم.
2. **Google Drive لأرشيف الصور والوثائق**:
   - يتم رفع صور المراجعين، والكتب الممسوحة ضوئياً عبر الماسح الضوئي (Scanner)، ومرفقات المعاملات مباشرة إلى مجلد مخصص في Google Drive.
   - يتم توليد روابط مشاهدة سريعة وربطها بسجلات الجداول.
3. **الحساب المعتمد**:
   - مرتبط بالحساب الرسمي للمطور (`htaleb725@gmail.com`).
   - إمكانية فتح الجداول مباشرة أو تصفح المجلد بنقرة زر واحدة من داخل لوحة التحكم.

## 🌐 النشر على Vercel أو Hostinger أو GitHub

### 1. النشر على Vercel:
1. ارفع المشروع إلى مستودعك على **GitHub**.
2. اربط المستودع في **Vercel** واضغط **Deploy**.
3. المنظومة تعمل مباشرة وترتبط بجدول Google Sheets السحابي ومجلد Google Drive.

### 2. النشر على استضافة Hostinger:
1. نفذ أمر البناء: `npm run build`.
2. ارفع محتويات المجلد الناتج `dist/` إلى مجلد `public_html` في استضافتك على Hostinger.

### 3. النشر المجاني عبر GitHub Pages:
1. من إعدادات المستودع في GitHub -> **Settings** -> **Pages**.
2. اختر **GitHub Actions** تحت خانة **Source**.
3. سيتم نشر المنظومة تلقائياً.

## 💻 التشغيل المحلي على الحاسوب (Localhost):

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```
سيفتح النظام على الرابط: `http://localhost:3000`
